# Proposed GitHub repository

**Repository name:** `structural-fragility-moe-reproducibility`

**Short description:**
Pre-publication reproducibility materials for measuring hidden expert dependence in sparse Mixture-of-Experts by exact counterfactual expert removal, with verified aggregate results and a minimal structural-fragility example.

**Release policy:** Add the full versioned research code and manuscript-associated artifacts after publication.
