# Public data sources

## scikit-learn Digits

- 1,797 handwritten digit examples.
- 64 pixel features and 10 classes.
- Distributed directly with scikit-learn.
- Used for the prospectively separated confirmation experiment.

## UCI Gas Sensor Drift at Different Concentrations

- 13,910 records.
- 128 sensor features.
- Six gas classes and ten acquisition batches.
- Used for the classification transfer study and the concentration-regression boundary study.

No new dataset was created by this project. Raw public datasets are not mirrored in this pre-publication repository.
