# Reproducibility scope during peer review

The public repository is intentionally **pre-publication limited**.

Public now:

- metric and intervention specification;
- protocol metadata;
- verified aggregate results;
- public-data information;
- minimal demonstration code.

Not public until publication:

- complete research training/evaluation implementation;
- unpublished manuscript TeX;
- full run/checkpoint archive.

The complete verified implementation is supplied to the journal as *Supplementary Code for Review*. The intended post-publication release is the full versioned code plus manuscript-associated reproduction artifacts.
